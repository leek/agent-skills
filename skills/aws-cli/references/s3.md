# S3 CLI Reference

Two CLIs: high-level `aws s3` (rsync-like) and low-level `aws s3api` (raw API).

## List

```bash
aws s3 ls                                    # all buckets
aws s3 ls s3://bucket/                       # objects at prefix
aws s3 ls s3://bucket/ --recursive --human-readable --summarize

aws s3api list-buckets --query 'Buckets[].Name' --output text
aws s3api list-objects-v2 --bucket B --prefix p/ --max-items 50
```

## Copy / move / sync

```bash
aws s3 cp file.txt s3://bucket/key           # upload
aws s3 cp s3://bucket/key ./                 # download
aws s3 cp s3://a/ s3://b/ --recursive        # bucket-to-bucket

aws s3 sync ./dir s3://bucket/prefix/        # mirror up
aws s3 sync s3://bucket/prefix/ ./dir        # mirror down

# DANGEROUS — deletes destination files not in source
aws s3 sync ./dir s3://bucket/prefix/ --delete
```

## Delete

```bash
aws s3 rm s3://bucket/key                    # one object
aws s3 rm s3://bucket/prefix/ --recursive    # DANGEROUS — confirm first
aws s3api delete-object --bucket B --key K --version-id V   # versioned
```

For versioned buckets: `delete-object` without `--version-id` only adds a delete marker. To truly purge, list versions then delete each.

## Bucket config

```bash
aws s3api get-bucket-location --bucket B     # region
aws s3api get-bucket-versioning --bucket B
aws s3api get-bucket-encryption --bucket B
aws s3api get-bucket-policy --bucket B --query Policy --output text | jq
aws s3api get-public-access-block --bucket B
```

## Presigned URLs

```bash
aws s3 presign s3://bucket/key --expires-in 3600
```

## Useful flags

- `--storage-class STANDARD_IA|GLACIER|DEEP_ARCHIVE`
- `--sse aws:kms --sse-kms-key-id <arn>`
- `--exclude "*" --include "*.json"` (s3 sync/cp filtering)
- `--dryrun` on `cp`/`sync`/`rm` (high-level only — confirm before destructive)

## Common mistakes

- `aws s3 ls bucket/` (missing `s3://`) → tries to list local file
- `--recursive` is **required** for prefix operations on `aws s3 cp`
- `aws s3 sync` follows symlinks by default — pass `--no-follow-symlinks` to avoid leaks
